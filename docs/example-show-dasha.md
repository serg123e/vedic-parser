# Пример данных: `show-dasha`

Всё ниже — настоящий ответ сайта, распарсенный тулами. Карта:
**Ss, 07.08.1983 23:00:00, UTC+4, 55°45' N 37°37' E** (Москва).

```sh
vedic-parser show-dasha --name Ss --date 07.08.1983 --time 23:00:00 \
    --latitude 55.45 --longitude 37.37 --timezone +4 \
    --dasha vimshottari --level 1
```

Ответ: `dasha`, `divisional`, `kind`, `level` и `periods` — список периодов. Самое ценное здесь в атрибутах строки, а не в тексте:

```html
<tr start="23.11.1978 16:25" end="23.11.1997 13:21">
  <td><span class="Sa">Saturn</span></td>
  <td>23 Nov 1978</td><td class="hide">16:25</td><td>-</td>
</tr>
```

Границы берутся из `start`/`end` и приводятся к ISO, а видимая дата (`23 Nov 1978` / `23 ноя 1978`) остаётся просто подписью — по ней парсить не надо.

## 1. Один период целиком

```json
{
  "start": "2004-02-17T07:42",
  "end": "2004-12-23T18:56",
  "lords": [
    "Me",
    "Su"
  ],
  "labels": [
    "Mercury",
    "Sun"
  ],
  "start_label": "17 Feb 2004",
  "start_time": "07:42",
  "age": 20
}
```

В этой таблице такой шов один: после Saturn-Jupiter конец `1997-11-23T13:20`, а следующий период начинается в `1997-11-23T13:21`. То есть на строгую непрерывность полагаться нельзя.

## 5. Шесть систем

| `--dasha` | Тип | Что это |
|---|---|---|
| `vimshottari` | планетная | основная, 120 лет |
| `yogini` | планетная | 36 лет |
| `ashtottari` | планетная | 108 лет |
| `chara_rao` | знаковая | Чара даша в трактовке К.Н. Рао |
| `narayana` | знаковая | Нарайана даша |
| `navamsa` | планетная | Навамша даша |

Плюс параметры `--divisional` (любая варга D1…D60), `--current` (какой отрезок последовательности вернуть, по умолчанию «сейчас») и `--cycle` (шаг целыми циклами — те самые стрелки ↓↑ в интерфейсе).
